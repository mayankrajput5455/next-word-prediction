# 🧠 Next-Word Prediction using LSTM (RNN)

An end-to-end Natural Language Processing (NLP) deep learning project that predicts the next word in a sequence using a **Long Short-Term Memory (LSTM)** neural network trained on a dataset of famous quotes. The project includes a Jupyter Notebook for model training/experimentation and a **Streamlit** web application for real-time interactive predictions.

---

## 📌 Features

- **Text Preprocessing & Tokenization**: Cleans raw text data, converts to lowercase, strips punctuation, and builds a vocabulary index.
- **N-Gram Sequence Building**: Generates input-target sequence pairs for language modeling.
- **Deep Learning Architecture**: Uses Embedding layers combined with LSTM units to capture long-term context in text.
- **Interactive Web Interface**: Streamlit UI allows users to enter custom prompts and instantly view predicted next words.
- **Artifact Serialization**: Saves model weights (`.h5`), tokenizer, and maximum sequence length configurations for seamless inference deployment.

## 🛠️ Data Pipeline & Model Architecture

### 1. Data Preprocessing
- **Dataset**: `qoute_dataset.csv` (3,038 quotes).
- **Cleaning**: Lowercasing, removing punctuation using Python's `string.punctuation`.
- **Tokenization**: Fitted using Keras `Tokenizer` with a maximum vocabulary size of 10,000 words.

### 2. Sequence Vectorization & Padding
- **Input Sequences ($X$)**: N-gram sequences generated by breaking sentences word-by-word.
- **Target ($y$)**: The target next word for each n-gram.
- **Padding**: Sequences are pre-padded (`padding='pre'`) to match `maxLen` (745).
- **One-Hot Encoding**: Target vectors are one-hot encoded into 10,000-dimensional categorical vectors.

### 3. Model Architecture
| Layer | Type | Configuration |
| :--- | :--- | :--- |
| **Embedding** | `Embedding` | Vocabulary Size: `10,000`, Output Dim: `50`, Input Length: `maxLen` |
| **Recurrent** | `LSTM` | Units: `128` |
| **Output** | `Dense` | Units: `10,000`, Activation: `softmax` |

- **Loss Function**: `categorical_crossentropy`
- **Optimizer**: `adam`
- **Metrics**: `accuracy`

## 🚀 Getting Started

### Prerequisites

Ensure you have **Python 3.8+** installed on your system.

### 1. Clone or Download the Repository

Navigate to the project directory:
```bash
cd "Project-01-RNN"
```

### 2. Set Up a Virtual Environment (Optional but Recommended)

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

## 💻 Usage

### Running the Web Application

Launch the Streamlit app to interact with the model via your browser:

```bash
streamlit run app.py
```

Once started, open `http://localhost:8501` in your browser, enter a prompt (e.g., *"The world as we have"*), and click **Predict Next Word**.

### Training & Notebook Experimentation

To re-train the model or explore the training pipeline:
1. Open `sentenceCompletion.ipynb` in Jupyter Notebook or VS Code.
2. Run the cells step-by-step to preprocess data, train `SimpleRNN` vs `LSTM`, and serialize updated `.pkl` and `.h5` files.
